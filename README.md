# Unfold SMP — сайт и публикация на GitHub Pages

## Структура

- `index.html` — главная страница.
- `assets/css/main.css` — стили.
- `assets/js/data.js` — редактируемый контент: правила, новости, состав, сезон.
- `assets/js/main.js` — взаимодействия и анимации.
- `assets/img/` — логотипы, иконка сайта и превью.

## Важно: загрузить все файлы

Если загрузить в GitHub только `index.html`, оформление и интерактивность не появятся: HTML отдельно обращается к файлам внутри `assets/`.

### Способ 1 — обычный проект (рекомендуется)

1. Распакуйте ZIP.
2. Откройте папку, где рядом лежат `index.html`, `README.md` и `assets/`.
3. Загрузите **содержимое этой папки целиком** в корень репозитория `unfoldsmp-site`. Не помещайте весь проект во вложенную папку `unfold-smp-deploy-package/`.
4. В репозитории должны лежать `index.html` и папка `assets` на одном уровне.
5. В GitHub откройте **Settings → Pages** и проверьте, что публикация настроена из нужной ветки и папки `/ (root)`.
6. После коммита откройте `https://whomeawl.github.io/unfoldsmp-site/` и обновите страницу принудительно: `Ctrl + F5`.

Правильная структура корня репозитория:

```text
index.html
assets/
  css/main.css
  js/data.js
  js/main.js
  img/...
.nojekyll
README.md
```

### Способ 2 — только один файл

В отдельном файле `index.html` из комплекта **Standalone** CSS, JavaScript и логотипы уже встроены. Его можно использовать, если хотите опубликовать только один HTML-файл: замените им `index.html` в репозитории. Для этого варианта папка `assets/` не требуется.

## Как менять контент

В обычном проекте отредактируйте `assets/js/data.js`. В нём находится конфигурация сайта и содержимое блоков. Стили — в `assets/css/main.css`.

## Перед публикацией

- Проверьте приглашение Discord в ссылках, если оно изменилось.
- `canonical` в HTML сейчас указывает на `https://unfoldsmp.fun/`. Если официальный домен другой, исправьте его.
- Адрес игрового сервера не добавлялся, поскольку его не было в исходных данных.
